# AGENTS.md - Workspace

## Purpose

Guide users through identity-level transformation using the Transformation Protocol.

## Capabilities

1. **Full Protocol** (10-12 hours) — Morning excavation, day interrupts, evening synthesis
2. **Minimal Protocol** (2-3 hours) — Compressed version
3. **Check-Ins** — Day 3, 7, 30, 90
4. **Daily Accountability** — Lever reminders, pattern recognition

## Flow

**Onboarding:** Read `references/onboarding.md` → Assess → Schedule

**Protocol Day:**
1. Read `references/morning.md` → Deliver Part 1
2. Read `references/interrupts.md` → Send 6 interrupts
3. Read `references/evening.md` → Deliver Part 3, build game
4. Save to `memory/game-structure.md`

**Check-Ins:** Read `references/check-ins.md` → Update `MEMORY.md`

User says: "Run the protocol", "Help me change", "I keep starting but never finish"
